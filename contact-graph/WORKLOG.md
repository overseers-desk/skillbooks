### Ignore pattern seed

`ignored_pattern_seed.sql` covers all four accounts (manual study + automated random-sample sweeps). Two tiers:

- **Tier 1**: local-part regex patterns (no-reply variants, MTA infrastructure, mailing list daemons, CI, bulk-sender tracking tags, etc.)
- **Tier 2**: pure relay/infrastructure domains (SendGrid, Amazon SES, Mailgun, Atlassian, Discourse, ESP subdomains, SaaS relay subdomains, vertical-specific relay domains, etc.)

Total: **98 patterns** seeded.

Note on PostgreSQL regex: `~` is case-sensitive by default; `(?i)` inline flags are used where case variance was observed. The seed SQL uses `''` to escape single quotes inside string literals (standard SQL).

### Candidate resolution pipeline (`resolve_candidates.py`)

Seven-phase pipeline written to resolve the 30,375 candidates into permanent tables:

**Phase 0** — seeds `ignored_pattern` (skips if already seeded; uses `psql` subprocess to avoid multi-statement SQL issues inside psycopg2).

**Phase 1** — prunes candidates in three passes:
1. Already-resolved (addresses already in `email_address`): -44
2. Self-addresses: -1
3. Ignore patterns (address/domain/regex types): -2743 (address: 12, domain: 572, regex: 2159)
→ 27,587 remaining

**Phase 2** — Xapian enrichment: queries `mu find contact:<addr>` for up to 200 blank display names. Enriched 58 of 200 queried.

**Phase 3** — display name clustering:
- Normalise: lowercase + sort tokens ("Weiwu Zhang" = "Zhang Weiwu").
- Exact match against existing humans: 98 addresses matched.
- Subset match: cluster tokens ⊆ existing human tokens (catches "Bárbara Quiñones" → Bárbara Quiñones Vásquez).
- Corporate filter: single token, too many tokens, contains dot/digit/parentheses, starts with "The", contains relay particles ("via"/"by"/"from"/"at"), corporate signal tokens.
- Personal-looking names (2–4 tokens, no corporate signals): auto-create human with `notes = 'corpus-derived'`.
- **7,838 new humans created** (some will be org names that slipped the filter; `notes = 'corpus-derived'` marks them for manual review).

**Phase 4** — domain ownership:
- `*.weiwu.au`, `*.weiwu.eu`, `*.weiwu.id.au` → Weiwu (id=1)
- `colourful.land` / `colorful.land` → Weiwu (1) unless display name contains "Liansu/Yu"
- `realss.com` → match display name against known realss humans
- 57 addresses assigned.

**Phase 5** — bulk INSERT into `email_address` (source='corpus', is_canonical=FALSE):
- 8,621 resolved (human_id set)
- 18,966 unresolved (human_id NULL)

**Phase 6** — corrected Aiqin Li address: `liaiqinlahzou@163.com` → `liaqinlanzhou@163.com`.

**Phase 7** — printed summary report.
