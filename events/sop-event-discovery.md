# Event Discovery

Search the web for upcoming events matching the interests below. For each event found, record the event name, organiser, date(s), location, a one-line description, and the source URL. If an event has an application or registration deadline that closes well before the event date (common for large tourism events like ATE), record both the deadline and the event date.

Write the results to `events/results/YYYY-MM-DD-discovery.md` (using today's date). Group events by interest area. Within each group, sort by date (earliest first). Only include events that haven't already passed.

## Areas of interest

### AI events
- Conferences, summits, and meetups about AI/ML.
- Located in Spain, Portugal, or significant EU-wide events.
- Events where AI angel investors meet startups (pitch days, demo days, investor meetups) — these can be anywhere in Europe.

### Skål International
- Skål club events in: Gold Coast, Brisbane, Cádiz, or Singapore.
- Skål national events in Australia.
- Skål international congress or global events.

### ACBC Queensland
- Networking events only (dinners, drinks, connection events, speed connect).
- Skip lectures, seminars, webinars, and briefings.

### Tourism industry
- Australian Tourism Exchange (ATE) — note both event dates and application/submission deadlines.
- Other significant Australian tourism trade events.

### AI + startup investor events
- Demo days, pitch competitions, and investor meetups with an AI focus.
- Europe, Australia, or Singapore.
