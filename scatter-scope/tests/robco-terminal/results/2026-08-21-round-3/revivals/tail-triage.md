# Tail triage: 25 flagged modules

Read-only pass over `/home/weiwu/code/RobCo-Terminal`. Disposition per rule: **by design** (shared vocabulary reading widely is the job), **artefact** (the count is the instrument's), **scattered (escalate)** (genuine multi-site decision, not closed here).

Recurring instrument note, confirmed by spot-checking several rows: A only counts *non-test* source files, so a module whose real consumers are test files (which do use its exact types) shows up as a B/leak gap that is not scatter. It is a consequence of A's own definition. That alone accounts for the leak lists of rows 2, 3, 13 and 24, which are 100% test files, and a large share of several others.
