# Decided-once facts, as the three blind estimators named them

Merged from the `## Decided once` sections of the three oracle replies, before any of them saw
code or a count. Where two or three named the same fact, the expected figure is the median of
what they gave; where one named it alone, it is that estimator's figure. The brief asked them to
include two kinds by name (the side a fixed panel sits on, and the unit a coordinate is carried
in); the rest are theirs.

| # | fact | expected places | named by |
|---|---|---|---|
| 1 | Which side of the window the channel bank sits on | 4 | 1, 2, 3 |
| 2 | The unit a coordinate is carried in (logical vs physical pixels) | 6 | 1, 2, 3 |
| 3 | The config file's format is TOML | 3 | 1, 2, 3 |
| 4 | The number and identity of the built-in chassis shells | 5 | 1, 2, 3 |
| 5 | The channel-switch chord is the modifier plus digits | 4 | 1, 3 |
| 6 | The window's floor height is 240 pixels | 3 | 1, 2, 3 |
| 7 | The default well width / default window size in logical pixels | 3 | 1, 2 |
| 8 | The tmux control-mode envelope is DCS 1000 p | 3 | 2, 3 |
| 9 | The GPU backend override env var is `WGPU_BACKEND` | 2 | 1, 3 |
| 10 | The config file's base name and per-platform directory | 2 | 1, 3 |
| 11 | Bitmap fonts render at integer scale | 3 | 2 |
| 12 | A second instance hands its request to the first | 2 | 2 |

`facts-measured.md` carries the measurement: for each fact, where it is **decided** (the
definition) and where it is **obeyed** (the consumers), the pattern used, and the homonyms the
probe excluded. A fact whose only handle is a common word is recorded as *not measured*, never
given a number.
