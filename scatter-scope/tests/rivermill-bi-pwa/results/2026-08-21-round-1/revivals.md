## Estimator e3

**Part A.**

**1. server/shared/access.js — A=1, B=1, C=8: measurement holds, and it's real.** (a) Count holds exactly. gate() and emptyAnswer() are the only exports; routeOf/missingRefs are module-private consts. Grepping for real importers of gate finds exactly one: server/shared/dispatch.js:78 (`import { gate } from './access.js'`). app.js and connector-tenant.js only mention access.js/gate() in comments, never import it. emptyAnswer appears nowhere outside access.test.js, where it's called 8 times, matching C=8 exactly. (b) The module's own doc claims "both dispatch and any non-dispatch surface... import gate() from here" and lists "the social branch pre-migration, the shell mounts in app.js" as callers; that is stale/historical prose; those paths have since been migrated onto dispatch.js as the single chokepoint. Every route in the platform now reaches the gate through one indirection layer, not by calling access.js directly. (c) By design: a deliberate single-caller chokepoint ("no sphere re-implements the decision... a second copy is a bug"), not scattering, not hiding. My A=20 guess wrongly assumed a security gate this central would be imported broadly; the actual design puts exactly one caller between it and every route.

**2. spheres/relationships/api/read.js — A=1 (not 3), B=0, C=0: count holds, corrected reasoning.** (a) B/C=0 confirmed outright: jsonStr, tripleKey, groupName, matchSide, personJson, buildPeople are all unexported module-private helpers (groupName is a parameter name). **Part B (four most consequential).**

**Connector HTTP transport, plain node:https, no SDK — measurement artefact, corrected ~20 files.** The literal-https probe only catches http-raw.js itself plus one test. But the design decision is centralized: http-raw.js is the only file that touches node:https/node:http; all 16 connector clients (xero, rezdy, clover, instagram, github, onedrive, facebook, googlechat, googlereviews, square, tiktok, deputy, dropbox, aws) plus 4 model-executor files import http-raw.js rather than requiring https directly. The fact is implemented once and consumed ~20 times through one shared transport; the probe missed the indirection layer entirely. Measurement artefact.

**Passwordless email sign-in — probe is a real homonym trap, confirmed.** `sign-?in` matches "signing"/"presigning" inside connectors/awsconnect/api/sigv4.js, presign.js, aws-client.js (AWS SigV4 request signing, unrelated), and separately catches genuine but different OAuth "sign-in" strings in onedrive/api/consent.js and dropbox/api/consent.js (each connector's own OAuth consent, not the platform's passwordless mechanism). The actual mechanism lives in server/shared/auth.js + web/src/lib/auth.ts, with a small, real set of direct consumers (app.js, AuthGate.tsx, chat.js, contract.js, tenancy.js, walls.js, credentials.js). Measurement artefact: the raw regex conflates three unrelated "sign" senses.

**Multi-tenant scoping — count roughly holds (318 files/7278 sites), and it's genuinely scattered, not miscounted.** Every match sampled (tenant_group, tenantOf, TENANT_ROW, tenant_member_grant, etc.) is a legitimate hit, no homonym noise found. But "expected places to edit if the fact changed" and "total mentions of the word" are different questions: the registry's own definition is small (31 files/222 sites), while the consumption of the tenant column is threaded through nearly every query in the codebase by design (the tenant-conformance test enforces this net). Scattered by design: the estimators' low guesses answered "where is it decided," the grep answered "where is it obeyed."

**Connector mirror-table prefix — probe measured the wrong noun.** Literal `connector_` only matches two registry tables (connector_credential, connector_tenant; "connector" the singular noun, unrelated to the per-connector prefix convention). The real convention is `<connector-name>_*` (xero_*, rezdy_*, instagram_*, sonas_*, etc.), a different string per connector, so no single regex catches it; true reach is 15+ connectors x their upsert/sync/read files, easily 40+ files. Measurement artefact.
