## What they have said publicly

**On open source security as collective responsibility (KubeCon North America 2024 keynote, November 2024):** Torres-Arias co-delivered the keynote "Open Source Security is Not a Spectator Sport" with Justin Cappos (NYU). The core message: anyone can contribute to security regardless of expertise — paths include taking classes, gaining hands-on experience, joining a security project, or finding a specialist group. This is a direct, public articulation of the view that security is a community obligation, not a specialist silo.

**On Sigstore's significance for the ecosystem (Sigstore project launch, ~2021):** Torres-Arias stated that Sigstore "will set a new tone in the software supply chain security conversation" and that "the software ecosystem is in dire need of something like it to report the state of the supply chain." He also stated he envisions Sigstore helping to "identify security issues and secure critical software infrastructure." Source: Linux Foundation press release and Sigstore blog.

**On NIST supply chain guidance (NIST SP 800-204D, published February 2024):** Torres-Arias co-authored "Strategies for the Integration of Software Supply Chain Security in DevSecOps CI/CD Pipelines" (with Ramaswamy Chandramouli, NIST, and Frederick Kautz, TestifySec). Upon publication he stated: "I'm confident that they will thoroughly inform and shepherd software engineers towards developing not only secure software but also to develop software securely." Source: Purdue ECE News, 2024.

**On in-toto's design philosophy (Kubernetes Podcast, Episode 174, ~2022):** Torres-Arias described in-toto as gathering "evidence of everything that happened through small pieces of metadata called in-toto links or in-toto attestations, which build a huge provenance graph that tells you where everything came from." He characterised in-toto as a way to "rubber stamp everyone's actions in a community." Source: Kubernetes Podcast from Google.

**On the KubeCon Europe 2025 panel (April 2025):** Torres-Arias participated in a panel titled "Open Source Malware or a Vulnerability? The Philosophical Debate and How To Mitigate" alongside Brian Fox (Sonatype) and Madelein van der Hout (Forrester Research). This signals active engagement with the conceptual framing of supply chain risk — not just technical implementation.
