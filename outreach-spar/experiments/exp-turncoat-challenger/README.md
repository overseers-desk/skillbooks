# Turncoat challenger

The persona step of the approach loop, run as three turns of one session instead of one prompt, so the reader reacts before it knows whose side it is on.

**Problem.** Blind reads of the current challenger prompt with the email withheld named the sender as the party it works for in 3 of 3 runs, citing "email draft", "role-play", "in-character", "credible" and the DONE/REVISE criteria; with a real profile inserted, 6 of 6 cited the profile's star rating, relevance assessment and campaign vocabulary. A reader that knows it is testing a pitch for the pitch's author reads analytically and forgivingly. The recipient it stands in for triages in seconds.

**Design.** Stage 1 (`prompts/stage1-triage.txt`) is a colleague's casual ask, speaker unnamed, with the contact's own facts and the email. Nothing of ours is in view, no later stage is in context, and the only fixed output is one word, reply or bin. Stage 2 (`prompts/stage2-matrix.txt`), a second turn of the same session, is the slow read: the sentence scores and the reader's graph from `../exp-writer-based-prose/prompts.md`, in one CSV. Stage 3 (`prompts/stage3-turncoat.txt`) reveals the side and asks for the translation the author needs. The verdict is stage 1's last word, taken before the reveal; stage 3 emits no verdict and revises nothing.

**Profile facts.** The profile body from `# Profile` up to the first of `## Catalogue evidence`, `## Relevance assessment`, `## Verification corrections`, front matter dropped, and the word "campaign" removed from the "Who they know" heading and column.

**Test.** Up to 8 round-2 letters from `../exp-writer-based-prose`, favouring ones the persona passed while carrying unresolved references, topped up with failed ones as controls. Same model as round 2 by exact id. One session per letter: stage 1, then stage 2 and stage 3 as resumed turns. One author revision per letter whose stage 1 said bin, so at most 8 emails are written. Sessions run from a directory whose path carries no repo name, under a config directory holding only the credentials, so no office methodology loads. Readout per letter: round-2 verdict; stage 1 last word; stage 1's quoted phrase for any reference it did not follow; whether it called the email misdirected or a scam; stage 2 rows scored 0 to 2 on resolution; stage 3's one change. Transcripts under `runs/`.
