# LinkedIn — platform module

Read before the first LinkedIn access in a session. Roster column: `linkedin_url`. Access runs through the shared logged-in session, one action per gate interval (about a minute), paced across all workers by the serialised browser. Within that lane the two access forms differ sharply: a direct profile-URL view is cheap, outside the search-rate protections and off-quota; search is rate-limited separately and draws down the account's Commercial Use Limit, which does not refill until the calendar month turns. So a known URL is fetched directly, and a search is spent only on a question no cheaper source answers.

- Name resolution: a company page's People section names the managing director or owner; company-page reads are cheaper than people-search.
- Employment-currency signals, captured verbatim when present: an "Open to work" / "#OpenToWork" banner, a "Providing services" / freelance section, or a headline whose named employer the current-experience entry or recent activity contradicts ("ex-", a different employer). Presence means the stated role may be ending.
- DOM parsing quirk: the profile parser sometimes returns category labels (e.g. "Startup") instead of company names, and splits one organisation's multiple roles into separate entries. Cross-reference by date overlap and description content; same-period entries describing one business are almost certainly one company.
- Self-listed contact info: the LinkedIn skill can read a member's shared Contact info (email, websites). Prefer that self-listed address over a pattern-derived guess; it is what the member chose to publish.

First touch: an unsolicited direct message from a stranger is, on LinkedIn, near-universally ignored or deleted; a connection request with a short note is the move the platform is built around. So the first touch is a connection invitation with the message as its note, whether or not the roster shows the person as an existing connection. Note length: 200 characters on a free account, 300 with premium; the validator enforces the 300 bound on every LinkedIn message. Some profiles offer no way to attach a note (a follow-first creator profile, an invitation limit, an email-required gate); the approach records `invitation_unavailable: true` and the dispatcher sends the note text as a direct message instead, which LinkedIn may still refuse.
