# Facebook — platform module

Read before the first Facebook access in a session. Roster column: `facebook_url`. Access runs through the shared logged-in session, paced across all workers by the serialised browser; there is no search quota, the per-site cadence is the whole constraint.

- Small operators (trades, local services, sole traders) frequently maintain their primary and sometimes only web presence here. Search for the company name; check the About section and any "Run by" attribution for the owner's name.
- A page is a channel source, not just an identity check: fetch both the main profile or page and its About page, and read the About/Contact and page-transparency sections for a published email address before concluding none exists.
- A person's listed workplace here is often more current than other sources; weigh it when sources disagree on the current role.
