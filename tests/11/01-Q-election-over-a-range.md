The input is the owner's almanac data root as it stood on 2026-09-21, copied read-only to a scratch folder so the blind run writes nothing into the owner's repository. The copy carries no git history, so the sweep window the year file's header omits is stated in the prompt as the owner would state it.

Follow `presence-move/move-methodology.md` with the data root at `<scratch copy>` for the range 2026-10-19 to 2026-11-30. The 2026 year file's last sweep covered 2026-08-17 to 2026-12-31.
