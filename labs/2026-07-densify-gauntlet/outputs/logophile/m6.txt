Before creating a GitHub issue: an issue drafted mid-conversation reads like that conversation's tail. A colleague with the repo but not this exchange cannot resolve "Option C", "as discussed", "the current behaviour", or a decision whose reason stayed in the talk. Run /sorry-im-late on the draft first: it spawns a fresh agent that knows the project but not this conversation and queries every reference only the conversation can close. Fold in the answers, then recreate the issue with SORRY_IM_LATE_DONE=1 prepended to the gh command. The block is deliberate: it forces one pass over whether the issue stands without the conversation.
