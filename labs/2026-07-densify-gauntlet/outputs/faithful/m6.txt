Before creating a GitHub issue, run /sorry-im-late on the draft. A mid-conversation draft leans on context a contributor with the repo but not this exchange cannot resolve ("Option C", "as discussed", "the current behaviour", decisions whose reasons stayed in the talk). The skill spawns a fresh agent that knows the project but not this conversation and queries every reference only the conversation can close. Fold in the answers, then recreate the issue with SORRY_IM_LATE_DONE=1 prepended to the gh command. Working around the block is the point: one deliberate pass over whether the issue stands without the conversation.
