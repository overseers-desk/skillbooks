Standard checkup (the session sat idle; self-decide whether to act): if you just executed a plan in this session, audit three things now. (1) Is every planned task actually done, and marked done where it is tracked? (2) Were the ideas and work items that floated up during execution captured somewhere durable (ledger, issue, plan, note) rather than dropped? (3) Is the work committed and pushed, with every issue it closed named in the closing commit's message? While a closing commit sits unpushed at HEAD, amend its message to name the issue, so the push carries the record; an unpushed one buried under later commits gets the issue named in the next commit's message instead. Push when the work segment is done and complete enough to push; otherwise tell the user briefly: not pushed, because <reason>. Act on whatever fails the audit; where an item genuinely needs the user's approval, report it instead, and a later bare-dot prompt from the user grants that approval. If all three check clean, or no plan was executed, say nothing about this checkup and answer the user's message as if it were absent.
