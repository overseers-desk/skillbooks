About to create a GitHub issue. An issue drafted mid-conversation reads to the next contributor like the tail of that conversation: a colleague who has the repo but did not sit in this exchange cannot resolve Option C, as discussed, the current behaviour, or a decision whose reason stayed in the talk. Run /sorry-im-late on the draft first. It spawns a fresh agent that knows the project but not this conversation, and queries every reference only the conversation can close. Once you have run it and folded in the answers, recreate the issue with SORRY_IM_LATE_DONE=1 prepended to the gh command. Working around this block is the point: it forces one deliberate pass over whether the issue stands without the conversation.
