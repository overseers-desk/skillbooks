# What the second pair taught, sorted by the clerk it changes

Source: the shift ledger of 20 September 2026 beside this file, its journal, and the two runs' four judges, two targeted judges and four owner's cold reads under `../2026-09-20-0031/stage-d/`. Each line is a lesson, its case in a clause, and the change it makes to a brief under `briefs/`. Survey-stage clerks come first, since a fault there is paid for at every later stage. Lessons that only a tool or a form could carry, which the owner's instruction keeps out of the method this run, close the file and point at the improvements entry that holds them.

## Records clerk

- Fourteen rows of one run's coded table were keyed by a bare file name, so a script splitting strata on the path dropped them: the inventory says what keys a row at each level, and the key carries the path a script splits on.
- Neither run's corpus had an operator column, and every rate in one run's findings counted one charity's template nineteen times and one company's fourteen: the inventory records, for each unit, the body that sets its terms, or says plainly that no such column exists and that every rate is a rate of units.
- Page addresses for a re-fetch were taken from the capture record's page list alone, and a document a first reader had used but named by file was never fetched, so its fields came back not captured: the capture record's document rows are part of the address list, and the inventory says which units hold documents nobody can reach.
- Re-fetched pages sat outside version control, so a disputed cell could not be re-read once the folder was gone: the inventory says where stored page text lives and whether it survives the run.
- Coders differed on whether a unit the survey recorded as unreachable gets a row: the inventory states the convention, and the coder brief repeats it, since a convention held by the orchestrator alone is a convention three coders invent.
- One run's search study opens with the venue's own query residue and page slugs: the fence index marks it as a mild channel for the venue's naming, so the orchestrator can weigh it before handing it to a clerk that must not see the venue.
