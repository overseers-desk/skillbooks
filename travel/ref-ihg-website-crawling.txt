# IHG Website Browser Automation Reference

This reference documents browser automation patterns for IHG hotel research, including search queries, hotel detail pages, and room specifications. Created from actual MCP browser sessions.

---

## IHG Website Structure Overview

The IHG website has two main navigation paths relevant to hotel research:

1. **Hotel Search** - Find hotels by destination, dates, and guest count
2. **Hotel Detail Pages** - View room specifications for a specific property

Both paths have direct URL access patterns, which should always be the first approach. Manual form interaction is a fallback when URLs redirect unexpectedly.

**Critical behaviour:** The IHG website frequently redirects invalid or unfamiliar URLs to a generic explore page (`https://www.ihg.com/explore`). If the browser lands on this page unexpectedly, the URL was incorrect or the website rejected the request.

---

## Hotel Search: Direct URL Construction

Direct URL access is faster and more reliable than manual form filling. Construct search URLs using this pattern:

```
https://www.ihg.com/hotels/gb/en/find-hotels/hotel-search?
  qDest=Vienna,%20Austria          # Destination (URL encoded)
  &qCiD=01                         # Check-in day (2 digits)
  &qCiMy=002026                    # Check-in month/year (0-indexed)
  &qCoD=05                         # Check-out day (2 digits)
  &qCoMy=002026                    # Check-out month/year (0-indexed)
  &qRms=1                          # Number of rooms
  &qAdlt=2                         # Number of adults
  &qChld=1                         # Number of children
  &qChAge=8                        # Child age(s), comma-separated
```

### Month Encoding (0-indexed)

The month parameter uses a non-standard 0-indexed format combined with year:

| Month | Code | Month | Code |
|-------|------|-------|------|
| January | 00 | July | 06 |
| February | 01 | August | 07 |
| March | 02 | September | 08 |
| April | 03 | October | 09 |
| May | 04 | November | 10 |
| June | 05 | December | 11 |

**Common error:** Using `012026` for January 2026 instead of correct `002026`.

### Example URLs

Vienna, Jan 1-5 2026, 2 adults + 1 child (age 8):
```
https://www.ihg.com/hotels/gb/en/find-hotels/hotel-search?qDest=Vienna,%20Austria&qCiD=01&qCiMy=002026&qCoD=05&qCoMy=002026&qRms=1&qAdlt=2&qChld=1&qChAge=8
```

Budapest, Jan 2-5 2026, 2 adults + 1 child (age 8):
```
https://www.ihg.com/hotels/gb/en/find-hotels/hotel-search?qDest=Budapest,%20Hungary&qCiD=02&qCiMy=002026&qCoD=05&qCoMy=002026&qRms=1&qAdlt=2&qChld=1&qChAge=8
```

## Hotel Search: Manual Form Interaction (Fallback)

Use manual form interaction only if direct URL access fails or redirects to the explore page.

### Step 1: Navigate to Search Page

```
https://www.ihg.com/hotels/us/en/reservation
```

A language/country banner may appear on first visit. Click "Yes" to accept English, or the banner will persist and obstruct interaction.

### Step 2: Destination Field

1. Click the Destination combobox (element typically labelled "Destination")
2. Type the city name slowly (e.g., "Vienna")
3. **Wait 2-3 seconds** for autocomplete suggestions to load
4. Click the appropriate suggestion from the dropdown

**Key behaviour:** The autocomplete requires a delay after typing. Proceeding too quickly results in no suggestions appearing.

### Step 3: Date Selection

1. Click the Check In date field to open the calendar picker
2. The calendar shows two months side-by-side
3. Navigate months using Previous/Next buttons if needed
4. Click the check-in date
5. The check-out field activates automatically
6. Click the check-out date

### Step 4: Guest Configuration

1. Click the "Rooms & Guests" selector (default shows "1 Room, 1 Guest")
2. Use +/- buttons to set Adults count
3. Use +/- buttons to add Children
4. **For each child added, an age selector appears** - this must be completed
5. Select each child's age from the dropdown

**Mandatory requirement:** Child ages must be selected before the search form will submit.

### Step 5: Execute Search

1. Click the "Search" button
2. Wait 3-5 seconds for results to load fully
3. Verify results by checking the hotel count message

## Hotel Detail Pages: Room Specifications

To view room types and sizes for a specific hotel, use the hotel detail rooms page.

### URL Pattern

```
https://www.ihg.com/[brand]/hotels/us/en/[city]/[hotel-code]/hoteldetail/rooms
```

**Important:** Use `/us/en/` in the path for hotel detail pages. The `/gb/en/` variant used for search may redirect to the explore page for hotel detail URLs.

### Brand Codes

| Brand | URL Segment |
|-------|-------------|
| InterContinental | `intercontinental` |
| Crowne Plaza | `crowneplaza` |
| Holiday Inn | `holidayinn` |
| Kimpton | `kimptonhotels` |
| Vignette Collection | `vignettecollection` |
| Hotel Indigo | `hotelindigo` |
| voco | `voco` |
| Garner | `garner-hotels` |

### Hotel Codes (Examples)

Hotel codes are property-specific identifiers:
- InterContinental Vienna: `vieha`
- InterContinental Budapest: `budhb`

**Common error:** Similar-looking codes exist for different properties. Vienna has codes like `vieha`, `viehc`, etc. for different hotels. Using the wrong code redirects to the explore page.

### Working Examples

```
InterContinental Vienna:
https://www.ihg.com/intercontinental/hotels/us/en/vienna/vieha/hoteldetail/rooms

InterContinental Budapest:
https://www.ihg.com/intercontinental/hotels/us/en/budapest/budhb/hoteldetail/rooms
```

### Page Content

The rooms page displays:
- **Room categories:** Separate "Our rooms" and "Our suites" sections
- **Room size:** In square metres (e.g., "Room Size: 45 sq. m. – 45 sq. m.")
- **Bed configuration:** (e.g., "Beds: 1 King Bed" or "Beds: 2 Twin Beds, or 1 King Bed")
- **Amenities:** Listed under "may include" (e.g., Lounge Access, Single Sofa Bed, River View, City View)
- **Photo carousel:** Multiple images per room type

### Critical Limitation: No Guest Capacity Display

**The rooms page does NOT show maximum guest occupancy.** This is the most significant limitation for family booking research.

To determine guest capacity:

1. **Booking flow method:** Search with specific guest count (e.g., 3 guests) and observe which rooms appear as available
2. **Web search:** Query "[Hotel name] [room type] guest capacity" - third-party sites sometimes publish this data
3. **Call the hotel:** Most reliable method, especially for edge cases like adding rollaway beds

## Interpreting Search Results

### Availability Indicators

| Status | Display | Meaning |
|--------|---------|---------|
| Available | "Only a few left from [price] per night" with active "Select Hotel" button | Room matching guest count exists |
| Unavailable | "No rooms available for selected dates" with "View Available Dates" button | No rooms for this guest count on any date in range |
| External | "Book on hotel site" | Non-IHG booking; rewards may not apply |
| Future | "OPENING SOON" badge | Hotel not yet operational |

### 3+ Guest Search Behaviour

When searching with 3+ guests, results only show hotels with rooms accommodating that number. Hotels with only 2-person rooms either:
- Do not appear in results
- Show "No rooms available for selected dates"

**Implication:** A hotel may appear available for 2 guests but unavailable for 3 guests. This indicates no family rooms exist, not that the hotel is fully booked.

### Currency Display

- Default currency varies by session/location (may show INR, EUR, etc.)
- Use "Hotel Currency" filter option for local pricing
- Prices are per night for the room, not per person

### InterContinental Vienna Suites

| Suite Type | Size | Bed | Sofa Bed |
|------------|------|-----|----------|
| Junior Suite (entry-level) | 45 sq.m. | 1 King | No |
| One Bedroom Suite | 50 sq.m. | 1 King | No |
| Senior Suite | 70 sq.m. | 1 King | No |

### InterContinental Budapest Suites

| Suite Type | Size | Bed | Sofa Bed |
|------------|------|-----|----------|
| Junior Suite (entry-level) | 29-39 sq.m. | 1 King/Queen | No |
| Grand Castle Suite | 48-51 sq.m. | 1 King | Yes |
| Presidential Suite | 100 sq.m. | 1 King | Yes |

### Comparison Insight

Vienna's entry-level Junior Suite (45 sq.m.) is larger than Budapest's (29-39 sq.m.), yet the IHG booking system may show Vienna's as 2-guest capacity while Budapest's Grand Castle Suite (with sofa bed) accommodates 3+. Room size alone does not determine guest capacity in IHG's system - the sofa bed presence is the key differentiator for 3+ guest accommodation.
