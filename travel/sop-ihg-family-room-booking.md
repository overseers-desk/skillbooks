# IHG Family Room Booking SOP

## Purpose

This SOP establishes the methodology for booking IHG accommodation for 3+ guests (typically 2 adults + children). It addresses the challenge that standard hotel searches hide partial-availability options and that 3+ person rooms often require expensive suite upgrades.

The procedure enables:

- Systematic discovery of hotels with 3+ person capacity using single-date search
- Date-specific availability verification via price calendar analysis
- Selection of appropriate booking strategy based on price differential

## Prerequisites

- Travel dates and cities identified
- Party composition known (number of adults, children, children's ages)
- Budget context established
- IHG Rewards Wallet checked for Confirmable Suite Upgrade voucher availability (if applicable)

## Procedure

Use the ihg.com skill for IHG queries (hotel discovery by destination, availability and pricing, price calendar, hotel details).

### Step 1: Single-Date Hotel Discovery

Search using a single date (preferably the last date of the trip) rather than the full date range. Full-range searches return only hotels with continuous availability across all nights—a hotel showing "no rooms" for Jan 1-5 may still have rooms for Jan 3-5.

Execute:

1. Search booking platform: [City], [single date], [3 people]
2. Apply filters: IHG brand, price range, star rating as needed
3. Record all hotels appearing in results (these have 3+ capacity on this date)
4. Do NOT book yet—this step identifies candidates only

### Step 2: Base Rate Discovery

For each shortlisted hotel:

1. Change search to 2 adults, same date
2. Record: hotel name, base room type, base price per night

### Step 3: Price Calendar Analysis

Determine which dates have 3+ person rooms available:

1. Open price calendar for the hotel
2. View with "2 adults" → note available dates
3. View with "3 people" → note available dates
4. Dates that disappear when switching to 3 people = no 3+ rooms on those dates

Record the availability pattern for each hotel. Note: price calendar is indicative, not real-time; verify availability at booking time.

### Step 4: Room Type Classification

For dates with 3+ availability, calculate price difference between 2-person and 3-person rooms:

- **≤€20/night difference**: Direct-bookable family room → Strategy 1
- **€20-€100/night difference**: Moderate upgrade → Strategy 2 (or Strategy 1 if acceptable)
- **>€250 difference for the booking**: Expensive upgrade (suite-level) → Strategy 3 if voucher available, since we only have 2 vouchers per year, only use it if it saves total booking cost of that specific booking more htan €250. Because a voucher can be used for a booking max 5 nights, the use of it usually leads to larger than €250 saving.

### Step 5: Multi-City Optimisation (if applicable)

When travelling across multiple cities:

1. Map availability gaps: if preferred city lacks 3+ rooms on certain dates, identify which alternate cities have availability
2. Split stay strategically across cities based on availability
3. Compare voucher value across cities: use voucher where (price difference × nights) is highest
4. Verify transport connections between cities when planning splits

## Booking Strategies

### Strategy 1: Direct Booking

**When**: Price difference ≤€20/night between 2-person and 3-person rooms.

**Execute**: Book directly for 3 people. Select refundable rate if available.

### Strategy 2: Pre-Booking Negotiation

**When**: Price difference €20-€200+/night, especially during low-occupancy periods.

**Key principle**: Call hotel BEFORE booking. The threat of booking elsewhere provides leverage.

**Execute**:

1. Find hotel's direct phone number (not booking platform, not central reservations)
2. Call during business hours
3. Script: "I am planning to visit [City] from [Date] to [Date] with my family (2 adults and [X] children). I am considering booking your hotel but need a room that accommodates us comfortably. I see you have suites available. If you can upgrade me to a suite at the standard room rate, I will book within the next hour."
4. If agreed: book immediately and reference the agreement
5. If declined: try next hotel on shortlist

### Strategy 3: IHG Confirmable Suite Upgrade Voucher

**When**: Total booking savings >€250, IHG Platinum status with voucher available, stay ≤5 nights.

The voucher upgrades to **entry-level suite or premium room only**—not any suite. Before planning to use the voucher for family accommodation, verify that the hotel's entry-level suite accommodates 3+ guests. If the entry-level suite is limited to 2 people, the voucher will not solve the family room problem for that hotel.

**Constraints**:

- Maximum 5 nights per voucher use
- Must call IHG Customer Care between 14 days and 24 hours before check-in
- Book refundable rate (fallback if upgrade unavailable)
- Cannot stack with other guaranteed upgrades
- Subject to suite availability (exceptions during special events/high demand)

**Eligible rates**: Best Flexible, Member Discount, Reward Night, Government, select Corporate/Package rates.

**Ineligible rates**: Group/convention rates, OTA/Wholesale rates, Employee rates, Prepaid rates with deposit applied.

**Participating brands**: InterContinental, REGENT, Vignette, Hualuxe, Hotel Indigo, voco, Crowne Plaza, Even, Holiday Inn, Kimpton, Garner.

**Excluded brands**: avid, Atwell Suites, IHG Army Hotels, IHG Residences, Six Senses, InterContinental Alliance Resorts Macau, Iberostar.

**Execute**:

1. Verify voucher in IHG Rewards Wallet
2. **Verify entry-level suite capacity**: Check the hotel's room types to confirm the entry-level suite accommodates 3+ guests
3. Book base room (cheapest eligible room, NOT the suite) with refundable rate
4. 14 days before check-in: call IHG Customer Care (number shown when clicking "Redeem" on voucher)
5. Provide booking confirmation number and request suite upgrade
6. If upgrade fails: voucher returns to Wallet within 5 business days; cancel booking if needed

**Voucher optimisation**: Survey all trip segments before using. Prioritise where total savings (price diff × nights) are highest, and prefer longer stays (4-5 nights) over shorter ones.

## Strategy Selection Logic

```
3-person room price difference from base:

≤€20/night → Strategy 1 (Direct Booking)

>€20/night:
  └─ IHG hotel + voucher available + savings >€250 total → Strategy 3 (Voucher)
  └─ Otherwise → Strategy 2 (Negotiation)
```
