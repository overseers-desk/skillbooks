# MIND — notes for AI sessions

How the market holds one trading name, and whether a movement in that standing is the operator's own, in four phases (Measure, Index, Name, Decide). `mind-methodology.md` is the whole procedure. It runs on the cadence the operator sets, on the trading name and the matched windows the operator names, and each run executes the same detector set and writes the same tables, so one run lies beside the last.

A run is a dated document in the campaign folder. It reads the prior run before it measures anything, pulls each detector the campaign's instrument list supplies over matched windows a year apart, for the whole and for each target market, calls a change a movement only past the detector's own threshold, reads a panel of comparable businesses on the same detectors, windows and markets, attributes each movement, and ends at Name with numbered findings under five fixed heads. Decide is the operator's phase; its table sits in the run and is read by the next one. The panel comes from the campaign's register of comparable businesses; the detectors' instances, the name term set and the theme list come from the campaign's instrument list; this document names only their kinds.
